# Assessment rubric

Score each dimension 1–4. A week passes at 3 or higher in Correctness and Safety, and an average of 3 or higher. A score of 1 requires remediation.

| Dimension | 1 — Needs support | 2 — Developing | 3 — Meets | 4 — Exceeds |
|---|---|---|---|---|
| Correctness | Does not work or evidence absent | Happy path only | Meets acceptance checks | Handles meaningful edge cases |
| Reasoning | Cannot explain choices | Explains mechanics | Connects choices to requirements | Compares alternatives with evidence |
| Testing | Little/no automation | Narrow tests | Appropriate layered tests | Strong failure and property coverage |
| Reliability & safety | Unsafe defaults | Some controls | Bounded, recoverable behavior | Anticipates compound failure |
| Environment ownership | Waits for mentor operation | Follows commands with support | Independently starts, inspects, cases, and recovers | Creates useful deterministic cases and improves tooling |
| Communication | Unclear status | Partial notes | Reproducible concise handoff | Excellent decision and incident narrative |

The mentor records evidence, not personality judgments. PowerShell syntax and Windows administration are not scoring dimensions. Environment ownership means learning the running system through supplied commands, evidence, and case design. Remediation must name the missing capability, a bounded exercise, and a re-review date.
