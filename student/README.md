# Student guide

Work week by week. Do not open the mentor directory. Keep your implementation in a separate Git repository or a `student-work` folder excluded from clean/reset operations. For every week submit: source, automated tests, `DECISIONS.md`, `RUNBOOK.md`, and a short evidence file containing commands and results. Never include secrets or private production data.

Before each exercise, start and smoke-test its environment. When a behavior surprises you, record the observation, hypothesis, experiment, and result. The review rewards sound reasoning more than accidental success.
