# Exercise 1: active source notes

**Time:** 4 hours
**Objective:** Build a working mental model of threat modeling, authentication, authorization, asymmetric keys, tokens, OAuth roles, secrets, input safety before implementation.

## Steps

1. Open [the source guide](../source-guide.md).
2. For every core source, record the problem, mechanism, guarantee, failure assumption, and signal.
3. Complete the listed workshop evidence.
4. Write three predictions about the local environment.
5. During the environment lab, mark each prediction confirmed, disproved, or unresolved.

## Output

Add a `Source notes` section to `EVIDENCE.md` with links, section names, notes, predictions, and unresolved questions.

## Hint

If a page is dense, begin with headings, examples, and normative terms; then return to the section that controls this week's exercise.

## Done when

Your notes can explain the concepts without copying paragraphs and each prediction names a measurable signal.
